# DS Interview Prep Sheet

A free, one-page tracker for data science and machine learning interview prep. It puts questions from DataLemur, LeetCode, HackerRank, Brainstellar, Project Euler and two free GitHub answer banks into one list. Questions that appear on two sites are merged, and there are **no paid questions**: every link opens free.

**Open it:** [harshreaver.github.io/DS-Interview-Prep-Sheet](https://harshreaver.github.io/DS-Interview-Prep-Sheet/), or download `index.html` and open it in Chrome or Edge. Nothing to install or sign up for.

## What's inside

- **633 items** (493 core, 140 optional), including HackerRank's free SQL certificate tests (Basic, Intermediate and Advanced), across SQL, pandas and Python, statistics and probability, machine learning, A/B testing and project prep.
- **Same question on two sites?** Both boxes tick together, so you never solve it twice.
- **Filters:** search (it also matches concepts such as "window" or "A/B"), level, "Core only" and "Hide done". The counts follow the filters.
- **Today's plan:** about 3 hours a day, every subject every week instead of one subject at a time. SQL and pandas come up every day, stats and ML on alternate days, and Sunday is a light day for a project or A/B item. Every question you solve comes back once, a week later, for a re-solve from memory, so earlier topics don't go cold.
- **Start here:** what data science interview rounds look like and what gets asked.

## Your progress

Ticks are saved in your own browser and are never sent anywhere. Clearing the browser's site data or switching browsers resets them.
